ONG ESPERANÇA - PROJETO FRONT-END

Estrutura:
- index.html: página inicial
- projetos.html: página de projetos sociais
- css/style.css: estilos do projeto
- js/script.js: menu responsivo
- img/: imagens/ilustrações utilizadas no site

Como abrir:
1. Abra esta pasta no Visual Studio Code.
2. Instale a extensão Live Server.
3. Clique com o botão direito em index.html.
4. Selecione "Open with Live Server".

Para a atividade:
- Use a árvore de pastas como demonstração da organização do projeto.
- Use a página no navegador para tirar os prints do resultado visual.
- Os arquivos da pasta img representam os assets utilizados.
